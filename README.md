# Cycle Sync — Period & Phase Tracker

A simple, beautiful web app that tells you which menstrual phase you're in and gives you symptoms, food recommendations, workout ideas, and tips for each phase.

## Features

- **Visual cycle wheel** showing your current day
- **4 phase breakdown**: Menstrual, Follicular, Ovulatory, Luteal
- **Symptoms, foods, workouts, and tips** for each phase
- **Google Calendar export** — adds 3 months of phases to your calendar
- **Remembers your settings** between visits
- **Works on phone and desktop**
- **Single HTML file** — no dependencies, no build step

## How to use locally

Just open `index.html` in your browser. That's it!

## How to deploy to GitHub Pages (get a shareable link)

1. Create a new repo on GitHub called `cycle-sync`
2. In Terminal, navigate to this folder:
   ```
   cd ~/Documents/bolor\ things/cycle-sync
   ```
3. Run these commands:
   ```
   git init
   git add .
   git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/cycle-sync.git
   git push -u origin main
   ```
4. Go to your repo on GitHub → **Settings** → **Pages**
5. Under "Source", select **main** branch and click **Save**
6. Your app will be live at: `https://YOUR_USERNAME.github.io/cycle-sync`
